# Draft recheck mandate (B) of the review benchmark

The research-based draft of the recheck mandate (slice 4.4, S44-D13), which the benchmark's configuration recheck-B puts in place of the launcher's own. It is the draft of `docs/slices/poc-4-4-stage-checklists/research.md` without its source tags; the runner sends only the text under the heading below.

## Mandate

Each answer of the author is a claim, not evidence: open the files it names and the tests that cover them before you decide. Accept a finding only when the code now does what the finding asked; otherwise re-raise it under its ID with what you saw. List every answer under `accounted`, and say `cannot determine` when the copy does not settle it. Report anything wrong or missing in what the fixes touched.
