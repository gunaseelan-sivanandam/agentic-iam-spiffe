This document is a plain‑English rendering of the command‑derived spec in `docs/test_spec.md`. It describes what the tests check using the Premise / Exercise / Outcome guard model, and lists evidence artifacts for audit and debugging. Negative tests must assert the expected denial reason, not just a generic failure, as reflected in the guard logic.
