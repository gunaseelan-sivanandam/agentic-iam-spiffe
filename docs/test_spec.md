# Test Specification

This document is a faithful specification of the test harness in `scripts/rogue_node_tests.sh`. It is intended to describe what the tests **actually do**, not what they are expected to do in theory. The test suite uses a guard model with three phases per test:

- **Premise**: proves preconditions (environment, connectivity, required files) are true before the test action runs.
- **Exercise**: performs the action under test and captures evidence.
- **Outcome**: asserts the expected result using strict checks; negative tests must match the expected failure signal (generic errors are not accepted unless explicitly allowed by the guard logic).

Artifacts are evidence files written to a per‑test directory (typically `$EVDIR` under `/tmp/rogue-tests` or the configured artifacts directory). They exist to support debugging and to prove each guard executed.

## How to read this document

Each test is listed with its ID and name, followed by a plain‑English description derived from the guard labels (no extra assumptions), the exact premise/exercise/outcome guard commands (or a precise summary plus key assertions), and the evidence files created or consumed by the test. If a test does not include a guard type, it is explicitly noted as `NONE (no <guard> in script)`.
